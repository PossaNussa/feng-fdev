COLONY SHIP DOWN
================

Join the crew of the CSV Meridian.

How to play
-----------
1. Unzip this folder anywhere (Desktop is fine).
2. Windows: double-click ColonyShipDown.exe
   Linux:   run ./ColonyShipDown
3. Type a name, pick a password, and press Play. The official server is
   already filled in. First time on a server? Use Register (or just Play).

Nothing is installed: everything lives in this folder, including your
settings. Delete the folder to uninstall.

Windows may show "Windows protected your PC" the first time, because this
is a new program without a paid code-signing certificate. Click
"More info" -> "Run anyway". The program is built from public source code
(Luanti engine, LGPL-2.1) and contains no installers or downloaders.

Controls: WASD move, Space jump, Shift sneak, Ctrl crawl (air ducts!),
right-click to use things,
I inventory, T chat, Esc menu. In chat: /job, /tasks, /claim, /music, /particles.

Hosting a server
----------------
The game is included, so this same folder can host:
   ColonyShipDown --server --gameid colony_ship_down --world worlds/csd --port 30000
(or double-click "Host Server.bat" on Windows / run ./host-server.sh on Linux).
