### PIXEL ANIMALS
---
![PXA](https://codeberg.org/pixelzone/pixel_animals/raw/branch/main/pixel_animals.jpg)

Pixel Animals is a mod that adds more animals to your world, some passive and others not.
I started this mod a few years ago and decided to finish it and share it with anyone who wants to have fun with it.
I will gradually add new animals and new items, so I hope you like it....

---

Some mobs don't appear if certain subgames or mods are installed, for example:
Turkeys and bats don't appear when "Animalia" is installed, as it already contains these mobs, making it more convenient to use both mods together.
Bats don't appear in Mineclonia and Voxelibre, as these mobs already exist in those subgames.

If you have any questions about animals, visit the ![WIKI](https://codeberg.org/pixelzone/pixel_animals/wiki/?action=_pages)
