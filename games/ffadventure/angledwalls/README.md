# Angled Walls

Angled placement for **any** block: stand at an angle, place a block, and it goes
in at that angle.

## How it plays

* Facing roughly along an axis (N/S/E/W) — blocks go down as plain cubes, exactly
  as they always have.
* Facing roughly along a diagonal (within 20° of 45°, configurable) — the block
  turns into its angled variant, chamfer facing you. Walk a diagonal placing
  blocks and the wall comes out as one continuous 45° surface.
* Holding **sneak** while placing on a diagonal gives the *corner piece* — one
  chamfered corner instead of two — which is what joins a diagonal run to an
  axis-aligned wall. The modifier key is configurable (`sneak`, `aux1`, `none`).
* Digging an angled block returns the ordinary block. There is nothing new to
  craft, carry, or find in the inventory.
* `/angled`, `/angled on`, `/angled off` — per-player toggle, remembered in
  player meta.

## How it works

Angled variants are generated at startup for every ordinary cubic block in the
game, whichever mod it comes from (`autogen.lua` runs in
`register_on_mods_loaded`, so no mod dependencies are involved). A block
qualifies when it is a plain cube a player could sensibly build with: cube-ish
drawtype, walkable, diggable, named, in the creative inventory, and without the
metadata, timer, or right-click callbacks that mark a machine rather than a
building block. Groups that would let another mod's ABM swap the node for a full
cube — `soil`, `spreading_dirt_type`, `falling_node`, `leafdecay`, … — are dropped
from the variant.

Variants are hidden from the creative inventory, are not craftable, and drop
whatever the plain block drops. Coloured blocks (`colorfacedir`, `color4dir`)
keep their palette colour when angled.

Placement itself is a `register_on_placenode` hook: the ordinary block is placed
through the normal path first, so protection, node replacement, and the block's
own `on_place`/`after_place_node` all behave as usual; only the shape is swapped
in afterwards.

The two meshes are chamfered cubes with separate mesh buffers for top, bottom and
sides, so textures land on the right faces (bark on the sides of a log, rings on
top) and line up with neighbouring cubes. They are generated by
`models/.dev/gen_angled_models.py`.

See `settingtypes.txt` for the settings, including the cap on how many nodes may
be generated.

## Changes from upstream

The hand-registered list of ~200 angled wall / low wall / corner nodes for a
fixed set of Minetest Game materials is gone, replaced by the generated variants
above; the old node names are aliased to the generated ones so existing builds
survive (low walls become full-height diagonals). `bakedclay.lua` and `quartz.lua`
are no longer loaded for the same reason. The legacy registration API in
`angledwalls.lua` is still there for mods that call it.

The separate decorative families — angled glass arches (`angledglass.lua`),
angled doors (`adoors.lua`), and sloped walls (`slopedwalls.lua`) — are untouched.
